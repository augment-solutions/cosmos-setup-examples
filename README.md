# Cosmos Setup Examples

Examples and helpers for setting up [Augment Cosmos](https://www.augmentcode.com/) environments and integrations.

- [environments/](./environments/README.md) – Multi-platform (Azure DevOps, Bitbucket, GitLab) one-liner installation script that clones a set of repos into your Cosmos environment.
- [jira/](./jira/README.md) – Jira MCP server setup so that Experts in Cosmos can interact with Jira.
- Webhooks:
  - [webhooks/Bitbucket.md](./webhooks/Bitbucket.md) – Send Bitbucket events to Cosmos to trigger Experts.
