# Cosmos Setup Examples

Examples and helpers for setting up [Augment Cosmos](https://www.augmentcode.com/) environments and integrations.

- [Git repo cloning script for Cosmos Environments](./environments/README.md): Multi-platform (Azure DevOps, Bitbucket, GitLab) one-liner installation script that clones a set of repos into your Cosmos environment.
- [Jira integration](./jira/README.md): Jira MCP server setup for enabling Experts in Cosmos to interact with Jira.
- Webhooks:
  - [Bitbucket webhooks](./webhooks/Bitbucket.md): Send Bitbucket events to Cosmos to trigger Experts.
  - [GitLab webhooks](./webhooks/GitLab.md): Send GitLab events to Cosmos to trigger Experts.
  - [Azure DevOps (ADO) webhooks](./webhooks/ADO.md): Send Azure DevOps events to Cosmos to trigger Experts.
